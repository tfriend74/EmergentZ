# EMERGENTZ

EMERGENTZ is a personal third-person zombie survival game for macOS. The player begins every run infected and must keep killing zombies to delay transformation while advancing through increasingly dangerous swarms and reaching campfire checkpoints.

## Project setup

- Unity 6.6.2 (`6000.6.2f1`)
- Universal Render Pipeline
- macOS target
- Unity Cloud disabled

Open the repository folder as a Unity project. Generated folders such as `Library`, `Temp`, `Logs`, and `UserSettings` are intentionally excluded from source control.

## Current state

This repository contains the clean Unity URP foundation. Gameplay systems have not been scaffolded yet.
